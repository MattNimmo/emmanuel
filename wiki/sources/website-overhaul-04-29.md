**TLDR:** Matt's intro call with Brianna (unnamed ministry website vendor) to evaluate a website rebuild. ECC's current site (WordPress/Elementor) lacks a clear identity and has no web expert on staff. Matt's direction: external-facing front door, not member hub. CCB integration confirmed. Summer 2026 refresh target. Vendor also flagged as capable of rebuilding ECC's music/worship site (currently Squarespace).

---

## ECC's Current Website State

- Platform: WordPress, likely with Elementor
- No web expert on comms team — updates are manual, slow
- Events calendar broken: someone must manually duplicate info from CCB to website
- Four location pages exist as sub-pages (not separate sites) under `emmanuelcc.org`
- **Identity crisis:** site is currently a mix of external (new visitor) and internal (member) content — unclear which it's trying to serve

---

## Matt's Direction

**Website = external-facing front door.** Primary call to action: plan a visit.

- Members use the app (PushPay) for internal info — campuses, men's cookouts, groups, etc.
- Website should not try to replicate app functionality
- Large information sections (events, groups) belong only if they serve a newcomer's decision
- Nate's reference benchmark: `one.church` — clean, strong CTA, no clutter

### App / Website Split (As Intended)
| Platform | Audience | Purpose |
|---------|---------|---------|
| `emmanuelcc.org` | New visitors | Plan a visit; learn about ECC |
| PushPay App | Members | Internal info, campus events, groups |

---

## Vendor Overview (Unnamed — Rep: Brianna)

- Ministry-specific custom platform; built by a software engineer owner
- Drag-and-drop CMS; not WordPress; proprietary
- Integrations: CCB (events, people, groups), PushPay, Planning Center, ChurchSuite
- **CCB integration confirmed** — events added in CCB auto-publish to website if set public; location-specific filtering available
- Live stream: pulls YouTube live feed automatically; ends when YouTube stream ends
- Sermon catalog: embeds external video (not native hosting); supports podcast feed
- User roles: Owner / Admin / Editor (page-level permission limits available)
- Unlimited users, unlimited pages

### CCB Event Integration (Matt's Key Question)
Events from CCB auto-populate to website event pages. Each event links back to CCB for registration. Auto-creating a full event page from CCB data is **not yet built** — Brianna flagged it as a feature request. Matt identified this would save 2+ hours/week of manual work.

---

## Pricing Tiers (Discussed)

- **Premium:** Standard managed plan; includes CCB/PushPay integration, live stream, members portal
- **Ultimate:** Fully managed — unlimited design requests, team builds pages within 24–48 hrs; includes custom mobile app + app management team

Matt is evaluating Premium (self-managed) vs. Ultimate (fully managed, given no web expert on staff).

### Build Options
- **Free** — minimal setup
- **Essentials** — basic theme setup
- **Tailored** — modified theme; likely fit given ECC's existing brand
- **Custom** — fully custom design

Matt's instinct: start with Tailored (see if a theme matches direction), escalate to Custom if needed. Wants to see themes before deciding.

---

## Additional Scope: Music/Worship Site

ECC operates a separate music/worship website (currently on Squarespace). Matt raised migrating it to this vendor as well — single platform for both sites. Brianna confirmed it's feasible based on what she saw (simple, clean site; CTAs: Listen / Book).
