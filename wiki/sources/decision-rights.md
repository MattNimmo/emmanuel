**TLDR:** A single-sheet Excel file defining the 1–5 Decision Rights scale used to classify whether a given decision belongs to a campus Location or to Central. Created by [[nathan-grams]].

---

## Source

- **File:** Decision Rights.xlsx
- **Format:** Excel, 1 sheet ("Sheet1"), 3 data rows, 6 columns
- **Author:** Nathan Grams (attributed based on context)

---

## Content

The file contains only the scale header definitions. No decision inventory or applied examples are included.

| Level | Label |
|-------|-------|
| **1** | Location Decision with Churchwide Mindfulness |
| **2** | Location Decision with Central Input |
| **3** | Requires Clarifying Ownership Conversation |
| **4** | Central Decision with Location Input |
| **5** | Central Decision with Location Awareness |
